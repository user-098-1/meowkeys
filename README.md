# 键盘喵

[下载 Windows 和 macOS 安装包](https://github.com/user-098-1/meowkeys/releases/latest)

## 从源码构建

请在仓库根目录运行对应命令。

| 平台 | 准备 | 构建命令 |
| --- | --- | --- |
| Windows 10 / 11 | .NET Framework 4.8 和 NSIS 3 | `powershell -File .\windows\build.ps1` |
| macOS | Xcode 命令行工具 | `bash macos/build.sh` |
