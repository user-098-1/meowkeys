# macOS 使用教程

## 下载安装

1. 到 [Releases 页面](https://github.com/user-098-1/meowkeys/releases/latest) 下载 `Meowkeys-<版本>-macOS.zip`（Intel 芯片与 Apple 芯片通用，支持 macOS 11 及以上）。
2. 双击 zip 解压，得到 `键盘喵.app`。
3. 把 `键盘喵.app` 拖入「应用程序」文件夹。

## 首次打开放行

应用目前没有购买 Apple 公证，第一次打开会被 macOS 拦截——这是未上架 App Store 的开源软件的常见现象，放行一次之后即可正常使用。

**第 1 步**：在「应用程序」中双击 `键盘喵.app`。

**第 2 步**：根据弹窗提示放行。

- 弹窗显示"无法验证开发者"：
  - macOS 14 或更早版本：**右键点击**应用图标，选择**打开**，在弹窗中再点**打开**。
  - macOS 15 (Sequoia) 或更新版本：右键"打开"已失效。先点弹窗里的**完成**，然后打开**系统设置 → 隐私与安全性**，拉到页面底部，点击**仍要打开**。
- 弹窗显示"已损坏，无法打开"（Apple 芯片的 Mac 较常见）：
  1. 打开「终端」应用（启动台或聚焦搜索"终端"）。
  2. 输入以下命令后回车（注意保留引号）：
     ```sh
     xattr -cr "/Applications/键盘喵.app"
     ```
  3. 重新双击打开。

**第 3 步**：授权键盘联动。首次启动请允许系统弹出的权限请求；若未弹出，到**系统设置 → 隐私与安全性 → 输入监控**，勾选 `键盘喵` 后重启应用。小猫只读取按键编号驱动动画，不会读取、记录或上传你输入的内容。

## 卸载

把 `键盘喵.app` 拖入废纸篓即可。样式、位置等设置保存在本机，重新安装后自动沿用。

## 从源码构建

在 Mac 上安装 Xcode 或 Xcode 命令行工具，然后从仓库根目录运行以下命令。

```sh
bash macos/build.sh
```

脚本会编译 Intel 和 Apple 芯片两个版本，合并为一个支持 macOS 11 及以上版本的通用应用。构建成功后，`macos/build/` 中会生成 `键盘喵.app` 和用于分发的 `Meowkeys-<版本>-macOS.zip`。

## 分发说明（维护者）

构建产物为临时签名（ad hoc），不能通过公证。要让用户免去放行步骤、双击即用，需要加入 Apple Developer Program，用 Developer ID 证书签名并通过 notarytool 公证后重新分发。
